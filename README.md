Python Calculator CLI App

1. Project Description

The Python Calculator CLI App is a simple and interactive command-line application developed using Python. It is designed to perform basic mathematical calculations through user input.

The application provides four basic arithmetic operations: addition, subtraction, multiplication, and division. Users can select an operation from the displayed menu, enter two numbers, and view the calculated result directly in the terminal.

The calculator continues running in a loop, allowing users to perform multiple calculations without restarting the program. It also includes input validation, exception handling, and division-by-zero handling to make the application more reliable and user-friendly.

This project demonstrates the practical implementation of fundamental Python programming concepts such as functions, loops, conditional statements, and user interaction.

2. Features

- Addition: Adds two numbers and displays their sum.
- Subtraction: Subtracts the second number from the first number.
- Multiplication: Multiplies two numbers and displays the product.
- Division: Divides the first number by the second number.
- Division by Zero Handling: Displays an appropriate message when the user tries to divide by zero.
- Invalid Choice Handling: Displays an error message if the user selects an option outside the available menu.
- Input Validation: Handles invalid numerical inputs using exception handling.
- Continuous Calculation: Allows users to perform multiple calculations without restarting the application.
- Exit Option: Allows users to safely close the calculator by selecting option 5.

3. Technologies Used

- Python 3.13.2: Used as the main programming language to develop the calculator.
- Visual Studio Code: Used as the code editor for writing and editing the Python program.
- Terminal: Used to execute the program and interact with the calculator.

4. Python Concepts Used

- Functions: Four user-defined functions are created to perform addition, subtraction, multiplication, and division.
- Loops: A "while" loop keeps the calculator running until the user chooses to exit.
- Conditional Statements: "if", "elif", and "else" statements are used to select and execute the required mathematical operation.
- User Input: The "input()" function accepts the user's menu choice and numerical values.
- Return Statement: The "return" statement sends the calculated result back to the main program.
- Exception Handling: "try" and "except" blocks handle invalid numerical inputs and prevent the program from stopping unexpectedly.

5. How to Run the Project

Follow these steps to run the calculator application:

1. Open the "Python_Calculator" project folder in Visual Studio Code.
2. Open the integrated terminal in VS Code.
3. Make sure Python is installed on your system.
4. Type the following command in the terminal:

py calculator.py

5. Press Enter to execute the program.
6. Select an operation from the displayed menu.
7. Enter the two numbers when prompted.
8. View the result in the terminal.
9. Select option 5 to exit the calculator.
